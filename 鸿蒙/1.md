# 鸿蒙开发
## 环境配置
1. 安装DevEco代码编辑器
官网：
建议盘符不选C、路径不能有中文或特殊符号
2. 创建项目
（1）创建项目（ide正中间有个加号的创建项目）
（2）选择模版（选择第一个模板）
（3）填写项目信息（项目名称；包名(规范：域名+项目名称)；存储位置；API版本；适配的终端）
3. 配置idea的UI界面和默认语言
   直接在界面中的设置中设置语言和UI样式就行很简单
4. 工程目录中的代码结构：
   代码文件：entry/src/main/ets/pages
   资源文件：entry/src/main/resources
## ArkTS 基础
1. 定义：ArkTs是TypeScriptd的超集，基于TypeScript进行扩充和提升
2. 数据类型：
基础数据类型：字符串、数字、布尔值
数组类型：一次性保存多个同类型数据
对象类型：保存对象类型数据
3. 函数：
   跟ts的写法一模一样
4. 箭头函数
   跟ts的写法一模一样
5. 基础组件
   掌握组件写法，使用组件布局界面
   ArkUI(方舟开发框架)：构建鸿蒙应用界面的框架组件，界面构建与显示的最小单位
   - 容器组件：布局
   ```typeScript
   // 组件名(){}
   Column(){}
   Row(){}
   ```
   - 内容组件：内容
   ```typeScript
   // 组件名()
   Text('内容')
   ```
