# ai-agent系统学习
## 先理解：什么是 AI Agent
在学习之前，首先需要建立对 Agent 的正确认知。AI Agent并非简单的大模型套壳，而是一个完整的闭环系统，其核心公式为：
Agent = LLM + Planning + Memory + Tooling + Feedback Loop。
大模型充当"推理中枢"(大脑),负责理解意图和指令；规划负责将复杂任务拆解为子任务，并支持自我反思机制；记忆模块提供短期状态存储和长期向量检索能力；工具模块通过API、代码解释器等实现对外部世界的操作了。反馈环则让 Agent 根据行动结果自主调整下一步动作。

一句话判断标准：传统AI是"问答式"，用户提问->模型回答->结束；Agent是"持续运行式"，能主动规划、调用工具、完成任务闭环。agent从对话模式变成“自主行动体”
